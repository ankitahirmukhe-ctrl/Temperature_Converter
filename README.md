# Temperature Converter

A simple and responsive temperature converter website built using HTML, CSS and JavaScript.

## Features

- Convert temperature between Celsius, Fahrenheit and Kelvin
- Displays all three converted values at the same time
- Shows error messages for empty or invalid input
- Prevents temperatures below absolute zero
- Responsive design for desktop and mobile
- Clean dark-themed interface
- Simple and user-friendly layout

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works

1. Enter a temperature value.
2. Select the unit from the dropdown.
3. Click the **Convert** button.
4. The converted values are displayed in Celsius, Fahrenheit and Kelvin.

## Conversion Formulas

**Celsius to Fahrenheit**

°F = (°C × 9/5) + 32

**Celsius to Kelvin**

K = °C + 273.15

## Validation

The project checks for:

- Empty input
- Invalid numbers
- Temperatures below absolute zero (-273.15°C)

## Responsive Design

The layout is designed to work on different screen sizes. On smaller devices, the input fields and result cards automatically adjust to fit the screen.
